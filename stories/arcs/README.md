# Arcs

Structured, multi-chapter story arcs — e.g. a 24-chapter manga-style arc. Each arc gets its own folder:

```
<arc-slug>/
  overview.md   — premise, theme, throughline, act structure
  chapters.md   — one short entry per chapter: goal, key beat, turn, hook
  chapters/     — actual chapter prose, one file per chapter, once written
```

Draw on material from `../ideas/` (seeds, plotlines, character concepts, scenes) when building an arc out. An arc's `overview.md` typically starts life as a developed idea in `ideas/plotlines/`.
